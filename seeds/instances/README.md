# Instances issues d'une co-construction

Aucune instance utilisateur éprouvée n'est fournie dans cette version initiale. L'exemple du catalogue reste une illustration.

Une capture partageable peut être ajoutée dans `IDENTIFIANT/record.json`, accompagnée de `IDENTIFIANT/harness/`. La fiche conserve le contexte, les graines parentes, la référence de décision lorsqu'elle existe, les observations et les limites. Voir le [guide des graines](../README.md).

Ne pas ajouter un harnais privé à ce dépôt public. Ne pas remplir une référence d'accord ou de résultat simplement pour satisfaire un validateur.
