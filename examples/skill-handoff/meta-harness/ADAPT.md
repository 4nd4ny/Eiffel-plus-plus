# Adapter la compétence concernée

Un changement de format touche les compétences de production et d’examen. Un changement de catégorie touche les entrées du lot, pas le code des skills. Si une nouvelle tâche requiert une compétence absente, la déclarer indisponible, puis la construire ou la réemployer et la qualifier avant utilisation. Réexaminer les remises affectées ; une nouvelle mission ne restaure pas un résultat ancien.
