# decider-livraison

Préconditions : lot autorisé et entrées `report` lisibles ; respecter le contrat commun. Lire seulement la tranche utile de ROUTAGE et les facteurs affectés de QUALITE.

Vérifier les empreintes des reçus et que la première évaluation porte sur la référence complète. Appliquer compare : aucune obligation ne peut être compensée ; égalité conserve la référence ; absence d’éligible laisse INCONCLUSIVE. Expliquer le périmètre réellement couvert, les contrôles manquants et les changements documentés. Une sélection expérimentale n’autorise pas un déploiement. Arrêter au budget du mandat ; un besoin nouveau ouvre un nouveau lot qualifié.

Postcondition : remettre `decision` à `product`, avec les limites et preuves réelles. Les fichiers sont des ports de mission ; une copie de code qu’ils désignent doit aussi être vérifiée par l’atelier. Vérifier la mission avec son empreinte initiale avant la remise. Un changement du contexte rend la mission périmée ; aucune compétence ne crée une autorisation ou une garantie d’indépendance.
