# modifier-moteur

Préconditions : lot autorisé et entrées `contract, plan` lisibles ; respecter le contrat commun. Lire seulement la tranche utile de ROUTAGE et les facteurs affectés de QUALITE.

Choisir la tranche dans ROUTAGE. Reproduire l’écart sur work avant correction. Préserver les frontières entre transformation pure, persistance et réseau ; un test de citations ne prouve pas la vérité des réponses et un dédoublonnage ne décide pas seul une fusion. Modifier le plus petit module cohérent, ajouter le cas de non-régression dans la copie de code. Documenter les choix réellement affectés et leurs conséquences métier. Figer le projet complet avec freeze et remettre le reçu avec son empreinte au coordinateur ; ne pas choisir son propre verdict.

Postcondition : remettre `candidate, rationale` à `audit`, avec les limites et preuves réelles. Les fichiers sont des ports de mission ; une copie de code qu’ils désignent doit aussi être vérifiée par l’atelier. Vérifier la mission avec son empreinte initiale avant la remise. Un changement du contexte rend la mission périmée ; aucune compétence ne crée une autorisation ou une garantie d’indépendance.
