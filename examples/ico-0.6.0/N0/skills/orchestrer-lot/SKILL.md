# orchestrer-lot

Préconditions : lot autorisé et entrées `request` lisibles ; respecter le contrat commun. Lire seulement la tranche utile de ROUTAGE et les facteurs affectés de QUALITE.

Lire la demande et le périmètre déjà autorisé. Nommer le résultat utile, les fichiers ou sous-systèmes concernés, les exclusions, les acteurs effectifs et au plus deux cycles. Conserver la référence complète. Remettre un mandat daté sans inventer une décision métier ; si une inconnue change les droits ou le comportement, la rendre visible et poursuivre seulement le travail indépendant.

Postcondition : remettre `mandate` à `stbl`, avec les limites et preuves réelles. Les fichiers sont des ports de mission ; une copie de code qu’ils désignent doit aussi être vérifiée par l’atelier. Vérifier la mission avec son empreinte initiale avant la remise. Un changement du contexte rend la mission périmée ; aucune compétence ne crée une autorisation ou une garantie d’indépendance.
