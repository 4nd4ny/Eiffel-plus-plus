# Périmètre publié

Cette publication répond à la demande d’ajouter la réalisation comme exemple Eiffel++. Elle n’exporte pas le produit ICO.

Inclus : brief partageable, profil de travail, provenance du patron public, justifications des trois niveaux, générateur et bibliothèque N1, N0 complet de consignes et d’outils, responsabilités, compétences, tests fictifs et observations agrégées autorisées. Le cœur N0 et la bibliothèque N1 correspondent aux fichiers utilisés dans la campagne privée.

Exclus : code original ou modifié d’ICO, données, noms d’organisation, spécifications métier détaillées, contrôles privés, compilateur embarqué de la campagne, chemins locaux personnels, empreintes détaillées du code, sorties brutes et identifiants. Ils restent dans le dossier local de travail. La restauration d’un défaut injecté n’est pas publiée sous forme de patch produit.

Le cas `fixtures/` est une création synthétique pour éprouver le même atelier. Il ne constitue pas une anonymisation du code ICO. Les fonctions générales et les résultats agrégés sont partageables ; un lecteur public peut reproduire les mécanismes avec ce cas, pas les onze sondes ICO sans les ressources privées.

La provenance N2 identifie les fichiers publics réellement consultés à la révision indiquée. Elle ne certifie ni une génération autonome par un second modèle, ni une acceptation d’entreprise. Les coûts et les limites de mesure sont décrits dans COMPARAISON.md.
