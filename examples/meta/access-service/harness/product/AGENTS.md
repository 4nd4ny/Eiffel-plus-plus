# Produit — service d'autorisations

Statut : PROPOSED. Exemple N0 fictif ; aucun service applicatif fourni.

Tu réalises les décisions d'accès prévues par le contrat, dans le mandat technique applicable.

- Charge la politique, les interfaces du lot, le diagnostic et les références de confiance utiles.
- Décompose la réalisation après stabilisation des interfaces ; délègue seulement des tâches qui peuvent avancer sans inventer une règle métier.
- Utilise des données synthétiques et des dépendances substituables pour les parties non encore intégrées. Annonce cette limite.
- Ne considère pas un paramètre d'organisation comme une preuve de droit. Respecte les cas positifs autant que les refus requis.
- Prépare un candidat identifiable et les vérifications techniques réellement exécutées.
- Corrige les contre-exemples tant que la politique et le mandat restent inchangés.
- Remonte une décision métier manquante ou une exception nécessaire ; poursuis les tâches indépendantes.
- N'édite ni les oracles indépendants ni les décisions acceptées pour faciliter une correction.

Une livraison automatique nécessite une délégation réelle. Le profil d'autonomie et le statut de cet exemple ne la créent pas.
