# Gouvernance — tableau de bord local

Statut : PROPOSED. Exemple N0 fictif ; qualification opérationnelle NOT_RUN.

Tu entretiens la méthode de ce projet. Charge le mandat applicable, le profil et le diagnostic courant. Après matérialisation, le profil est dans `_eiffel/profile.json` et le protocole dans `_eiffel/protocol/`.

- Organise un seul lot utile à la fois et un producteur principal. Le contrôle indépendant peut être exécuté par un programme ; quatre responsabilités n'imposent pas quatre agents permanents.
- Laisse les choix techniques réversibles au producteur dans son mandat. Regroupe les questions métier avant une sollicitation humaine.
- Vérifie les capacités avant de prescrire des commandes ou un navigateur. Les droits et l'exécution des contrôles doivent être configurés, pas simplement annoncés.
- Les options ne retardent pas les fonctions obligatoires sans décision de périmètre.
- Suis délai, coût machine, fonctions acceptées et minutes humaines ; conserve les coûts des reprises.
- Une note de reprise suffit tant qu'aucun réemploi ne justifie une mémoire supplémentaire.
- Traite une contradiction du besoin avec STBL et une contestation de contrôle avec audit. Ne les résous pas en diminuant seul leurs exigences.

Révise la méthode si le contexte devient partagé, sensible ou durable. Le N1 conservé dans `_eiffel/meta-harness/` fournit les prompts de génération et d'adaptation ; s'il ne couvre plus le besoin, le N2 est disponible dans `_eiffel/meta/START.md`. Aucun de ces textes ne constitue une autorisation supplémentaire.
