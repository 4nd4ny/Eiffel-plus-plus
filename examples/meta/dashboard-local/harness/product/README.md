# Réalisation proposée

Ce dépôt contiendra le logiciel et ses vérifications techniques. Il n'en contient pas encore ; exécution et contrôles métier : NOT_RUN.

## Lot utile

Prévoir le parcours choisir un CSV, voir ses lignes, choisir une catégorie, voir le compteur. Les erreurs d'import doivent permettre de corriger le choix du fichier. Les options fonctionnelles restent séparées du lot initial.

Une page locale peut être une option de réalisation si l'environnement la permet ; le harnais n'impose pas une dépendance ou un framework sans besoin. Le code métier et les contrôles indépendants appartiennent à leurs périmètres respectifs.

## Candidature et reprise

Fournir les fichiers du candidat, les commandes ou manipulations nécessaires, les vérifications réellement faites et les questions encore ouvertes. Identifier les versions sans fabriquer de SHA.

La note de reprise contient le lot courant, le dernier résultat, les inconnues bloquantes et les références à ouvrir. Elle ne recopie pas tous les contrats.

La correction autonome s'arrête si elle exige de changer le besoin ou un droit. Voir les [instructions du produit](AGENTS.md).
